| **4. Persistent Notification** | Foreground service must display ongoing notification | `NovaVoiceForegroundService` builds channel with `NotificationManager.IMPORTANCE_LOW` and ongoing icon | **PASS** |
| **5. Stop Voice Action** | Notification must contain accessible stop action | `buildNotification()` binds `ACTION_STOP_VOICE` PendingIntent | **PASS** |
| **6. Screen-Off Operation** | Audio capture when device display turns off | Android 16 aggressive Doze & power restrictions pause unprivileged recognition | **CONSTRAINED / EXPECTED** |
| **7. Lock-Screen Behavior** | Access from lock screen without authentication | Voice UI remains secured behind device lock screen | **PASS** |
| **8. Background Operation** | Audio capture when another app is in foreground | Permitted only while persistent foreground notification is visible | **PASS** |
| **9. Process Termination** | Behavior when user swipes app from recents | `onDestroy()` in service explicitly cancels recognition and releases audio focus | **PASS** |
