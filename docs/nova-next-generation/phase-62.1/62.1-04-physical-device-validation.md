## 1. Physical Device Lifecycle Validation

1. **Step 1: Application Start:**  
   - `MainActivity.onCreate()` invoked.  
   - Reads session token from `SecureSessionManager`.  
   - Enqueues `DeviceHeartbeatWorker` via WorkManager.  
   - Server registers heartbeat acknowledgment.
2. **Step 2: Close and Reopen Application:**  
   - Activity terminated via back gesture.  
   - Reopened: `MainActivity.onCreate()` fires.  
   - `WorkManager.enqueueUniquePeriodicWork()` preserves existing scheduled task under `ExistingPeriodicWorkPolicy.KEEP`.  
   - Immediate one-time heartbeat dispatched successfully.
3. **Step 3: Network Disconnection & Restoration:**  
   - Network connectivity toggled off: WorkManager pauses `DeviceHeartbeatWorker` execution.  
   - Network restored: `NetworkType.CONNECTED` triggers immediate worker resume.
4. **Step 4: Permission Revocation State Detection:**  
   - When Notification Access is revoked in Android OS settings, `NotificationManagerCompat.getEnabledListenerPackages` detects the change.  
   - Heartbeat reports `isNotificationAccessGranted: false`.  
   - Capability status immediately transitions to `PERMISSION_NOT_GRANTED`.
