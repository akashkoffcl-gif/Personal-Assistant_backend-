### 2. Flashing Command Specification
To execute seamless installation without wiping local SQLite or encrypted Keystore session data:
```bash
D:\PT\platform-tools\adb.exe -s adb-10BF2413RD003BT-1KXSF1._adb-tls-connect._tcp install -r -d D:\PT\latest-apk\app-debug.apk
```
- `-r`: Reinstalls an existing application, retaining all user data, Room databases, and preferences.
- `-d`: Allows version code downgrade if ever required.
