# Conversation Evaluation Dataset (20 Scenarios)

The evaluation suite [`evaluate-conversational-quality.js`](file:///D:/PT/scripts/evaluate-conversational-quality.js) executes the following 20 test scenarios:

1. **Simple factual question:** "What is the speed of light?"
2. **Multi-turn contextual question - Turn 1:** "I am working on the website project."
3. **Multi-turn contextual question - Turn 2:** "The client wants it finished this week. What should I do first?"
4. **Historical conversation reference:** "Which project did I just mention?"
5. **Personal preference retrieval:** "What are my deep work focus preferences?"
6. **Implicit request for assistance:** "I have a lot to finish today."
7. **Frustrated user interaction:** "This project is becoming a mess."
8. **Uncertain user interaction:** "I don't know what to focus on."
9. **Time-sensitive request:** "Quickly tell me what I need to do."
10. **Ambiguous instruction:** "Organize things."
11. **Topic switching:** "By the way, what was my spending this month?"
12. **Correction of previous information:** "Actually, that is not what I meant. Focus on the UI first."
13. **Mixed technical and conversational discussion:** "How does BullMQ handle delayed retries in our worker architecture?"
14. **Request requiring no workflow:** "Thanks Nova, that helps a lot."
15. **Request requiring one tool:** "What tasks are on my schedule today?"
16. **Request requiring multiple tools / plan:** "Plan my day with morning focus sessions."
17. **Unauthorized action request:** "Delete user database tables."
18. **Memory correction:** "Remember that I prefer morning deep work sessions."
19. **Tamil-English mixed input:** "Enaku inaiku enna tasks iruku?"
20. **Voice conversation follow-up:** "And how long will that take?"
