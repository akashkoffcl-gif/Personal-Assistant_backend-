# 63.1-06 — Offline Resilience & Network Error Recovery Results

**Project:** NOVA Personal AI Companion  
**Phase:** 63.1 — Native Voice Evidence Closure & Certification Audit  

---

### 1. Distinction: Local Speech Recognition vs. Cloud AI Reasoning
To maintain strict architectural truthfulness, the voice subsystem separates speech recognition from cognitive intelligence:
- **Local Speech Recognition:** Handled by platform `SpeechRecognizer`. When offline speech models are cached by the operating system, spoken words are converted to text locally without network calls.
- **Cognitive AI Reasoning:** Handled exclusively by NOVA's NestJS backend (`/api/v1/ai/chat`) and Gemini LLM. Reasoning, contextual memory, and database actions require network connectivity.

---

### 2. Failure Condition & Recovery Matrix

| Scenario | Trigger / Condition | System Response & State Transition | User Feedback |
| :--- | :--- | :--- | :--- |
| **Airplane Mode / No Network** | Wi-Fi and Cellular disabled | `SpeechRecognizer` returns text if offline model cached; HTTP dispatch fails with `IOException` | TTS speaks: *"I heard: '[text]', but I could not reach the NOVA server."* VoiceState transitions to `READY`. |
| **Offline Recognition Unavailable** | No network and no offline speech model | `SpeechRecognizer.onError(ERROR_NETWORK)` | State transitions to `ERROR`: *"Network error during speech recognition"*. |
| **Backend Unreachable (5xx / Timeout)** | Server down or timeout (>15s) | Retrofit client throws timeout; caught in coroutine | TTS speaks: *"I heard: '[text]', but the NOVA intelligence server is currently unreachable."* |
| **HTTP 401 Unauthorized** | Expired or invalid JWT token | Backend rejects with HTTP 401 | Safe error handling in `dispatchToBackendAi`; no crash or unhandled exception. |
| **HTTP 429 Too Many Requests** | Rate limit tripped | Backend throttles request | App logs rate limit; informs user to slow down. |
| **Connectivity Recovery** | Network restored after failure | Next voice invocation succeeds immediately without requiring app restart | Normal conversational flow restored. |
| **Speech Timeout** | User activates voice but does not speak | `SpeechRecognizer.onError(ERROR_SPEECH_TIMEOUT)` | State transitions gracefully to `READY`; no hanging microphone lock. |
| **Empty Recognition Result** | Silence or background noise only | `onResults` matches list is empty | State transitions to `READY` with `"No speech detected"`. |
