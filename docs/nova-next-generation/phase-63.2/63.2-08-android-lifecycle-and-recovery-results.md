# 63.2-08 — Android Lifecycle and Network Recovery Results

**Project:** NOVA Personal AI Companion  
**Phase:** 63.2 — Fresh APK Build, Physical Installation & Native Voice Certification  

---

### 1. Android 16 (API 36) OS Lifecycle Behavior

| Lifecycle Event | System Action & Observed Behavior | Outcome |
| :--- | :--- | :---: |
| **Permission Revocation** | User revokes `RECORD_AUDIO` in device Settings; app detects `ERROR_INSUFFICIENT_PERMISSIONS` | State transitions to `ERROR`; app prompts user to restore permission |
| **User Stop Action** | Notification action `ACTION_STOP_VOICE` clicked | Service halts, notification dismissed, audio focus returned |
| **App Backgrounding** | User moves app to background while voice service running | Service continues running with ongoing microphone notification |
| **Aggressive Doze / Screen Off** | Screen turned off | Android 16 pauses background recognition loops to prevent battery drain |
| **Process Destruction** | App swiped from Recent Apps | `onDestroy()` releases TTS, destroys `SpeechRecognizer`, abandons audio focus |
| **Device Reboot** | Device restarted | Service does not auto-start on boot (strictly follows user-initiated mandate) |

---

### 2. Network Fault & Error Recovery Trace

| Condition | Observed System Response | User Experience |
| :--- | :--- | :--- |
| **Airplane Mode (Offline)** | Offline recognition captures text if model cached; HTTP dispatch fails with `IOException` | TTS speaks: *"I heard: '[text]', but I could not reach the NOVA server."* VoiceState resets to `READY`. |
| **Backend 5xx / Timeout** | Request times out (>15s) | Safe fallback speech informing user that intelligence server is unreachable. |
| **HTTP 401 Unauthorized** | Expired or invalid Bearer JWT | Backend returns HTTP 401; app logs authentication failure without crashing. |
| **HTTP 429 Too Many Requests** | Rate limit exceeded (<5s interval) | Throttling message returned; prevents backend overload. |
| **Connectivity Recovery** | Network restored | Next voice interaction executes normally with zero residual state locks. |
