## 1. Field-by-Field Telemetry Trace

| Metric / Field | Android Origin | Transmission Payload | Backend Persistence | Frontend Display | Fallback if Unavailable |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`pendingQueueCount`** | Room SQLite `notificationEventDao.getPendingEvents().size` | `pendingQueueCount: Int` in `DeviceHeartbeatRequest` | Checked in-flight during heartbeat | Displayed in Runtime Health card | Defaults to `0` |
| **`oldestPendingEventTime`** | Min `occurredAt` among pending Room entities | `oldestPendingEventTime: String?` | Validated in DTO | Displayed in queue metrics | Defaults to `null` ("Queue Clean") |
| **`lastSuccessfulSync`** | Timestamp of last HTTP 200/409 event sync | `lastSuccessfulSync: String?` | Updated on `mobile_devices.lastSeenAt` | Displayed as localized sync time | Uses device `lastSeenAt` |
| **`lastSyncError`** | Last exception or HTTP error code in sync worker | `lastSyncError: String?` | Transient telemetry | Displayed as error badge if present | Displays "None" / Clean state |
| **`isListenerConnected`** | `NotificationManagerCompat.getEnabledListenerPackages` | `isListenerConnected: Boolean` | Persisted in `mobile_permissions` | "Connected & Active" badge | Shows "Disconnected / Standby" |
| **`isNotificationAccessGranted`** | Android Package Manager listener check | `isNotificationAccessGranted: Boolean` | Persisted in `mobile_permissions` | "Granted" badge | Shows "Permission Required" |
| **`isBatteryOptimizationIgnored`**| `PowerManager.isIgnoringBatteryOptimizations` | `isBatteryOptimizationIgnored: Boolean` | Persisted in `mobile_permissions` | Security/Exemption status card | Shows "Optimized (May throttle)" |
