## 1. Lifecycle Verification Matrix

| Trigger Event | Implementation Mechanism | Verified Behaviour | Evidence / Log Tracing |
| :--- | :--- | :--- | :--- |
| **App Startup** | `MainActivity.onCreate()` | Inspects `SecureSessionManager.getAuthToken()`. If token present, schedules periodic heartbeat and triggers immediate ping. | `DeviceHeartbeatWorker.enqueueImmediate(this)` |
| **Post-Authentication** | `NovaNativeBridge.syncAuthSession()` | Triggered when user signs into WebView. Automatically initiates device pairing and enqueues heartbeat. | `DeviceHeartbeatWorker.schedulePeriodic(context)` |
| **Periodic Background** | `PeriodicWorkRequestBuilder(15, MINUTES)` | WorkManager schedules unique periodic work (`nova_periodic_heartbeat_worker`) with network constraint. | `WorkManager.enqueueUniquePeriodicWork(..., KEEP)` |
| **App Restart** | `MainActivity.onCreate()` | WorkManager policy `ExistingPeriodicWorkPolicy.KEEP` ensures scheduled job remains registered across activity restarts. | Preserved by WorkManager database |
| **Device Reboot** | `WorkManager` OS initialization | WorkManager automatically reschedules registered periodic work after system boot without requiring custom broadcast receivers. | Standard Android WorkManager guarantee |
| **Network Restored** | `NetworkType.CONNECTED` constraint | WorkManager pauses dispatch when offline and fires immediately when network connectivity is restored. | Constraints builder verified |
| **Device Revoked** | Backend `status: REVOKED` | Backend returns HTTP 401 Unauthorized. Worker aborts and returns `Result.failure()`, stopping retries. | Verified in `DeviceHeartbeatWorker.doWork()` |
